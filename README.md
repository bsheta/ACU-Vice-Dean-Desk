# ACU Vice Dean Desk

لوحة يومية لكلية الهندسة، خريف ٢٠٢٦–٢٠٢٧. يحدد الموقع اليوم بتوقيت القاهرة ويمكن اختيار تاريخ آخر.

- التدريس: ورقة Engineering من MASTER 9 FACULTIES FALL 2026_Eng.xlsx، مع بنود G025 المؤكدة للأربعاء من PDF المرفق. تُجمع الساعات المتجاورة المتطابقة في القاعة والمقرر. تظل التغطية مقيدة ببيانات الماستر والمراجعة.
- القاعات: سجل القاعات المستخدمة في بيانات الهندسة. تُراجع إشغالات التدريس وماستر الكليات وامتحانات التاريخ المختار بحسب تداخل الفترات. تُحجب 3405 يوم الثلاثاء لورودها في مستند العمارة دون وقت مصدق في الماستر.
- الامتحانات: ملف ACU Midterm Exam Schedule - Faculty of Engineering - Fall 2026.xlsx. تُطابق المراقبات من كشف التوزيع 2026-10-26 21-17 حسب التاريخ والوقت والكود والقاعة؛ الحالات غير المؤكدة تبقى ظاهرة كذلك.
- بيانات التدريس تتكرر أسبوعيًا. التغييرات الطارئة والإجازات والحجوزات خارج المصادر تحتاج تأكيد المكتب.

- جدول الامتحانات النهائية (مقترح) خريف ٢٠٢٦–٢٠٢٧، من 26/12/2026 إلى 17/01/2027: [PDF](exams/final-fall-2026/final-exam-schedule-fall-2026.pdf) · [Excel](exams/final-fall-2026/final-exam-schedule-fall-2026.xlsx). نسخة التوزيع فقط، بدون أسماء الطلبة أو المراقبين.

للتشغيل المحلي: `python3 -m http.server 8080`. يُنشر الموقع تلقائيًا من جذر فرع `main` عبر GitHub Pages.
