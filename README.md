# ACU Vice Dean Desk

واجهة مكتب وكيل كلية الهندسة لشؤون التعليم والطلاب، خريف ٢٠٢٦–٢٠٢٧.

- جداول التدريس من الملف المرفق «جداول كلية هندسة فصل خريفي 2027.pdf». يعرض الموقع صفحاته الأصلية حسب القسم.
- امتحانات منتصف الفصل من «ACU Midterm Exam Schedule - Faculty of Engineering - Fall 2026.xlsx». تعرض الواجهة تاريخ الامتحان ووقته والمقرر والقاعات.
- يشمل الموقع الشعارين المعتمدين لجامعة الأهرام الكندية وكلية الهندسة.

للتشغيل المحلي، شغّل `python3 -m http.server 8080` في مجلد المشروع. يُنشر الموقع تلقائيًا من جذر فرع `main` عبر GitHub Pages.
